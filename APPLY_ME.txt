MEOW ISLAND v4 (adds home-screen widgets). Apply on top of v3. Unzip INTO your project folder (e.g. C:\si).
One command per line in PowerShell. If your browser saved it as 'meow-island-v4 (1).zip', use that name.

  cd C:\si
  Expand-Archive -Path "$env:USERPROFILE\Downloads\meow-island-v4.zip" -DestinationPath C:\si -Force

CHECK (each must print one line; if one prints nothing the old file is still there):

  Select-String -Path plugins\kotlin\MeowWidgets.kt -Pattern "object MeowWidgets"
  Select-String -Path plugins\kotlin\IslandModule.kt -Pattern "pinWidget"
  Select-String -Path plugins\withIsland.js -Pattern "MeowHeatWidget"
  Get-ChildItem plugins\widgets\res -Recurse -File | Measure-Object | Select-Object Count      # expect 11

Then (prompt must say PS C:\si>):

  npx expo prebuild --platform android --clean
  cd android
  .\gradlew.bat assembleRelease -PreactNativeArchitectures=arm64-v8a

After installing: long-press the home screen > Widgets > Meow Island, or use Settings > Home screen widgets.
